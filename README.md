# Aaditya Kumar Gaurav — portfolio

A single-page React site built with Vite.

## Run it

```bash
npm install
npm run dev
```

Open the local URL Vite prints, usually http://localhost:5173.

## Other commands

```bash
npm run build    # production files in dist/
npm run preview  # serve the production build locally
```

Profile copy lives in `src/data.js`. Sections are React components in `src/components/`.
